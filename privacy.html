Privacy Policy

Last updated: October 10, 2026

Kadin's Homelab Health Sync ("the app") is a personal tool used only by its owner, Kadin Elbakkouri.

Data the app accesses

With the owner's consent, the app reads activity, health-metric (such as heart rate, heart-rate variability, oxygen saturation and breathing rate) and sleep data from the Google Health API, using read-only scopes.

How the data is used and stored

The data is stored in a private database on the owner's home server and is used only to produce personal charts and analysis for the owner. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account permissions. On request, the stored data is deleted from the home server.
