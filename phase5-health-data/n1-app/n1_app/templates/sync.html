Wearable sync

Use this only when the Google Health importer says its refresh token expired. The token never belongs in this page, chat, or Git.

1. Create a replacement token

Open Google OAuth Playground ↗

In the gear menu, select Use your own OAuth credentials, then use the existing client from the kad-health project.

Open kad-health OAuth clients ↗

2. Request the same read-only scopes

googlehealth.activity_and_fitness.readonly
googlehealth.health_metrics_and_measurements.readonly
googlehealth.sleep.readonly

Authorize with your Google account, then exchange the authorization code for tokens.

3. Save it privately on the server

Run this in your terminal. It prompts for the refresh token without echoing it.

ssh kadin@100.79.132.39 'cd /home/kadin/homelab2 && python3 scripts/update_google_health_refresh_token.py'

After saving it, return here and tell Codex “token updated” so the daily importer can be restarted and verified.
