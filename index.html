Kadin's Homelab Health Sync

A personal, single-user tool that copies my own Fitbit activity, heart-rate and sleep data from the Google Health API into a private database on my home server, so I can chart and analyze it.

It is not a public service. No one else can sign up, and it only accesses the Google account of its owner.
